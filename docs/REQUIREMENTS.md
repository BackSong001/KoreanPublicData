# 요구사항

## 기능
1. 수집기는 페이지네이션, 날짜 범위, API 오류·호출량 제한, 재시도와 지수 백오프, 요청 간격 및 타임아웃을 처리한다. 나라장터 요청은 최대 7일 단위로 분할한다.
2. 원천별 자료를 source_type, source_id, source_url, title, organization, published_at, deadline_at, budget_amount, description, collected_at으로 정규화한다. 없는 값은 null이다.
3. 중복은 원천 ID, 공고번호·차수, 정규화 URL, 제목·기관·날짜 순으로 판단하고 가능한 변경 이력을 보존한다.
4. 공식 링크와 이용 조건을 확인한 첨부파일만 다운로드한다. PDF·TXT·CSV 텍스트를 지원하고 미지원 파일은 링크와 처리 불가 상태를 유지한다. OCR·DOCX·HWP·HWPX는 후순위다.
5. 원본, 정규화 자료와 분석 결과를 분리 저장한다. 분석 실패가 원본을 손실시키지 않는다.
6. 분석은 문제, 불편, 요구사항, 고객, 목적, 기술, 소프트웨어 해결 범위와 미검증 가설을 추출한다. 고객 유형은 B2B, B2G, B2C, B2B2G, UNKNOWN이며 분야와 복수 기술 태그를 분류한다.
7. 근거 수준은 원문 명시 DIRECT, 합리적 추론 INFERRED, 근거 부족 INSUFFICIENT다. 인용과 위치를 원문에 연결하고 불일치 및 URL·예산·날짜를 검증한다.
8. 아이디어는 이름, 문제, 사용자, 기능, 기술, 1인 개발 기간·비용 추정, 난이도 1~5, 2주·4주 범위, 검증과 위험을 포함한다. 추정은 공식 값이 아니다. 복사와 Markdown 내보내기를 지원한다.
9. 검색·필터는 키워드, 고객 유형, 분야, 기술, 기관, 예산, 근거 강도, 2~4주 구현 가능 여부와 최신순을 지원한다. 목록은 페이지네이션한다.
10. 저장·메모·상태·비교는 로그인 사용자별로 격리한다. 관리자 작업은 서버에서 관리자 권한을 검증한다.
11. 수집·분석 성공과 실패, 중복, 마지막 갱신, 호출량과 비용을 기록하고 실패 재시도를 지원한다. 작업 중복 실행을 막는다.

## 품질 및 보안
서버에 비밀을 보관하고 입력을 검증한다. RLS, 인증·인가, 파일 크기·형식 제한, SSRF 방어, 타임아웃과 안전한 오류 처리를 적용한다. 외부 문서는 신뢰할 수 없는 입력이며 시스템 명령이 아니다. LLM 호출량·비용을 제한하고 느린 분석은 비동기로 처리하며 결과를 캐시한다. 접근성과 반응형 화면을 지원한다.

## 필수 검증
정규화, 날짜 분할, API 오류·호출 제한, 중복 제거, AI 스키마, 근거 연결, 검색·필터, 사용자별 저장, 관리자 권한 및 대표 사용자 시나리오 E2E를 Mock으로 테스트한다. 실제 API는 인증 후 공식 응답과 이용 조건을 검증한다.
