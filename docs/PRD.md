# ProblemRadar 제품 요구사항 문서

## 목적
대한민국 기업과 공공기관의 공개 자료에서 실제 요구와 미해결 문제를 찾아 개발자, 대학생, 창업자, 기획자와 연구자가 프로젝트 주제를 검토하도록 돕는다. 입찰 참여보다 문제 발견과 근거 검증에 집중한다.

## 핵심 흐름
공공 데이터 수집 → 정규화·중복 제거 → 문서 텍스트 처리 → 문제 추출·분류 → 원문 근거 검증 → 프로젝트 아이디어 → 저장과 비교. 원문에 명시된 사실, AI 추론, 생성 아이디어를 사용자에게 분명히 구분한다.

## MVP
- 나라장터 입찰공고 및 사전규격 자료 수집, 이력과 실패 관리.
- 문제 검색, 고객 유형·산업 등 필터, 근거와 출처가 있는 상세 화면.
- 문제별 소프트웨어 프로젝트 추천과 2주·4주 범위, 검증 방법 및 예상 비용 표시.
- 로그인 사용자별 관심 문제 저장, 메모, 상태 변경, 비교 및 삭제.
- 관리자 수집·분석 상태, 수동 수집, 실패 재시도와 호출량·비용 확인.
- 인증 없이 실행 가능한 테스트 데이터 모드. 테스트 데이터임을 명시한다.

## 데이터 범위
나라장터 입찰공고정보서비스와 사전규격정보서비스가 필수다. 기업마당은 선택적인 정책·산업 수요 보조 자료이며 직접 구매 수요와 동등하게 취급하지 않는다. 민원·NTIS 등은 인증, 이용 조건과 공식 API를 확인한 뒤 확장한다.

## 화면
`/` 대시보드, `/problems` 탐색, `/problems/[id]` 상세, `/ideas` 추천, `/saved` 관심 문제, `/admin` 관리자. 한국어 기본, 밝고 절제된 반응형 리서치 UI를 사용한다.

## 완료 기준
실제 자료를 수집할 수 있는 인증 환경에서 공식 출처가 연결된 문제를 탐색·필터링하고, 사실과 추론을 구분해 아이디어를 확인·저장하며, 관리자가 수집과 오류를 관리할 수 있다. 키 없는 Mock 모드와 테스트·프로덕션 빌드도 통과해야 한다. 외부 인증이 없으면 실제 연동은 미검증으로 보고한다.

## 후순위
개인 AI 채팅, 이메일, 채용공고·민원·NTIS 수집, 고급 클러스터링, 아이디어 공유, 시장 규모·경쟁사 분석은 MVP 이후로 미룬다.
